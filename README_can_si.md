# CAN FD 总线 SI 验证模型（两电机 + 分叉）

OrCAD 全家桶（Capture + PSpice AD）用，参照 `ragtime_florid` / `dm_mc02` 的 FDCAN：
仲裁 1 Mbps / 数据 5 Mbps，双绞差分线 120Ω（单线奇模 60Ω，vf~0.78）。

## 文件

| 文件 | 说明 |
|------|------|
| `can_si_2motor.cir` | 理想收发器版（纯内置元件，先跑这个理解拓扑/反射） |
| `can_si_2motor_transceiver.cir` | 真实收发器版（TI TCAN1042-Q1 SPICE 模型，正式模型） |
| `models/TCAN1042-Q1.TSM` | TI 官方 TINA-TI 宏（原版，`https://www.ti.com/lit/zip/sllm403`） |
| `models/TCAN1042_q1_pspice.lib` | 由 TSM 转写的 PSpice 明文版（OrCAD 用这个，含 2 个覆盖补丁） |
| 本文件 | 任务目的 / 步骤 / 判据 / 验证状态 |

## 收发器模型与修复（关键）

**来源**：TCAN1042-Q1 暂态 SPICE 模型 = `https://www.ti.com/lit/zip/sllm403`
（SLLM403.ZIP 内含 `TCAN1042-Q1.TSM`，9892 B，TINA-TI 二进制宏格式）。
注意区分：sllm301/302=SN6505、304=TCAN1042HGV IBIS、**305=tcan1042_q1.ibs（IBIS 非暂态）**、
306/307=TCAN1051 IBIS、308=TUSB1002 S 参数。另 `sllm402` 是 TINA 参考设计（TSC），内含同一网表。

**转写**：解析 TSM 二进制网表（每条记录 = [1 字节长度][len-1 文本][5 字节零填充]），
逐行转成 PSpice 明文：`VALUE = {expr}` → `VALUE {expr}`；行为逻辑、迟滞、阻抗原样保留。
自检通过：括号平衡、26 对 SUBCKT/ENDS、无残留 TINA 写法。

**确认的模型参数**：
- 引脚顺序：`.SUBCKT TCAN1042 TXD STB RXD CANH CANL VCC GND`
- 接收器差分阈值 0.9V（≥0.9V 判 dominant → RXD 低）
- 驱动器 RON≈36Ω，悬空 ROFF≈25kΩ；TXD 迟滞 0.8/2.0V；输入差分阻抗 54kΩ//12pF

**✅ TXD 极性（已实测定论）**：**TXD 低(0V)=dominant、TXD 高(5V)=recessive**，与真实 CAN
收发器一致（active-low）。PSpice 17.4 实测：TXD=0 → CANH 被 36Ω 驱动高、差分≈2.2V；
TXD=5 → 总线释放、差分≈0。**RXD 与 TXD 电平同相**（RXD 低=收到 dominant）。

**⚠ 模型需 2 个覆盖补丁才能正确工作（已内嵌在 .cir 里）**：
TSM→PSpice 转换中 `MUX2X1_0`（RXD 选通）和 `LOGIC_IO_0`（RXD 输出级）这两个
VSWITCH 数字级在 OrCAD 17.4 下行为错误/收敛失败。已在 .cir 里 `.lib` 之后用
等价的纯 EVALUE 子电路覆盖（PSpice 同名子电路后者胜）：
- `MUX2X1_0`：`OUT = IF(STB>2.5V, RXD2, RXD1)`
- `LOGIC_IO_0`：`RXD = IF(INP>2.5V, VDD, 0)`
驱动链（BUF_0/PREDRIVER_0/DRVRCAN_0/STBMODE_0）与接收器（HSRCVR_0/LPRCVR_0/RECV）
隔离实测全部正确，无需改。STB 高=待机（总线接地）、STB 低=正常，极性正常。

**模型无 recessive 偏置**：不驱动时总线靠 60Ω 终端拉到≈0V（差分≈0），共模≈2.44V（模型泄漏位）。
SI 差分观察不受影响，但别把 CANH/CANL 单端对地电压当绝对电平。

**单跑结果（S_STUB=0.3m，5Mbps 位序列）**：
- 显性稳态差分 ≈ 2.25V（≥1.5V 判据，裕量 0.75V）；隐性差分 ≈ 0。
- 单隐性放电（长显性后）：板端 5ns 内释放，桩端/远端 15~25ns 内 RXD 回到隐性；差分下冲 -0.26V。

**PSpice 17.4 实测坑（全部已验证）**：
- **没有 `.MEAS`/`.MEASURE` 命令**（HSPICE/LTspice/ngspice 家族才有）——任何写法都报
  `ORPSIM-16056`（该错误=`.` 后命令名无效）。改为 `.PRINT TRAN ...` 落盘 + Probe 交互测
  （Trace>Evaluate Measurement）。pspug 第 18 章只是 Probe 交互测量表达式，不是点命令。
- **节点名前缀规则**：`V(name)` 输出引用对 A/B/J/K/M/N/P/Q/T/U/X/Z 及 `_` 开头拒绝

- **T 元素 bug**：电路里有无损耗 T 线时，`.PRINT/.PLOT/.FOUR` 的**节点引用全挂**

## 这个任务是做什么的（目的）

CAN FD 数据段 5 Mbps 时一个比特只有 200ns，走线是**传输线**：
- 关节间线缆长度 + 分叉(stub) + 终端电阻 → 阻抗不连续 → 反射/过冲/振铃；
- 采样时刻电平穿越 0.5V 阈值 → 误码/丢帧 → 现场"总线偶发失败、电机掉线"。

**用仿真在硬件/接线前把物理层验证掉**：
1. 把真实 FDCAN 收发器模型放进仿真软件；
2. 复刻真实走线（板卡→电机1→电机2、分叉长度、终端）；
3. 某节点发 CAN FD 消息，看每个节点差分波形 CANH−CANL；
4. 看各节点收发器 RXD 是否还原出 TXD 位序列。

## 怎么做（步骤）

1. **拓扑**：3 节点 = 板卡(发) + 电机1(分叉处) + 电机2(末端)。线长按实际布线填（默认 1m+1.5m、分叉 0.3m）。
2. **终端**：只两端各 60Ω(CANH→GND)+60Ω(CANL→GND)。分叉电机1 **不终端** = 反射源（要验证的点）。
3. **激励**：板卡 TXD 5Mbps 位序列 `1101000110`（含长显性后单隐性放电最坏工况）。**按实测极性：dominant 位=0V、recessive 位=5V**。
4. **跑仿真**：psp_cmd（无头）或 PSpice AD F11。
5. **看波形**：Probe `V(CANH_B)-V(CANL_B)`/`V(CANH_M1)-V(CANL_M1)`/`V(CANH_M2)-V(CANL_M2)` 差分 + `V(RXD1/2/3)`，RXD 应与 TXD 位序列一致（仅差传播延时）。
6. **扫描裕量**：取消 `.STEP PARAM S_STUB LIST 0.25 0.5 1.0 2.0 3.0` 注释重跑，看分叉长度对振铃/下冲的影响；再拆一端终端模拟"忘焊终端"。

## 判据（5 Mbps 数据相，bit=200ns）

| 项目 | 合格标准 |
|------|----------|
| 各接收点差分峰值 `VDIFF_*` | ≥ 1.5 V（本模型实测 ≈2.25V，裕量 0.75V） |
| 远端残压 `VNEG_M2` | 接近 0（recessive 应回落，不留持续振铃） |
| 采样点（200ns×70~80%） | 稳定，无振铃穿越 0.9V 阈值 |
| RXD1/2/3 | 与 TXD 位序列一致（延时=传播+器件延迟） |
| 经验 | 5Mbps 下 stub 往返 1m≈8.5ns≈4%bit → **S_STUB 尽量 ≤0.5m**（1m 附近桩端下冲最深） |

## 模型局限

1. TI 模型是**行为级**：驱动强度/边沿/上下限都有，但封装寄生、共模抗扰、地电位差（电机独立供电）**没建**。
2. 要验共模/地弹/屏蔽层：加"地网络+共模源"，或换 IBIS 模型做系统级 SI。
3. 无损线：没算线损/趋肤，几米内可接受。
4. 电机 PWM 大电流对总线的传导/辐射耦合没建模（EMC 另类仿真）。
5. 理想版是单端模型（差分对折成一条线）；真实收发器版是双线差分模型。
6. 端口模型转换的两处 EVALUE 覆盖（MUX2X1_0/LOGIC_IO_0）只做数字传递，不影响总线电气行为。
